# V.A.D. release roadmap

1. Build visual flow canvas with draggable, connectable nodes.
2. Import HA automations read-only; retain source metadata and unsupported constructs.
3. Implement visual properties, undo/redo, drafts, and recommendations.
4. Build deterministic simulator and regression tests.
5. Validate in isolated Home Assistant; gate any publishing behind explicit approval and rollback.

No changes to live Home Assistant are authorised by this roadmap.
